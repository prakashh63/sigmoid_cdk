# Changelog

## 0.1.0

- First release: SecureBucket, WebDistribution, ServerlessBackend (multiple Lambdas and API Gateways),
  SQS with dead-letter queue, EventBridge rules, KMS-encrypted log groups, per-function IAM roles.
- Aspects: tagging, cdk-nag compliance, IAM guardrails, optional permissions boundary.
- GitHub Actions: CI, release, manual deploy.
